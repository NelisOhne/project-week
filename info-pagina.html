Opleidingsinformatie: Software Developer

Wil je leren hoe websites en apps worden gemaakt? Tijdens de opleiding Software Developer bij ROC Nijmegen leer je programmeren en werk je aan verschillende softwareprojecten.

Wat houdt de opleiding in?

Je leert software maken door zelf met code aan de slag te gaan. Je oefent met programmeeropdrachten en werkt aan projecten. Daarbij leer je niet alleen code schrijven, maar ook problemen oplossen, je werk testen en samenwerken.

Programmeren

Schrijf code en ontdek hoe je daarmee een website of applicatie bouwt.

Problemen oplossen

Onderzoek waarom iets niet werkt, zoek een oplossing en probeer die uit.

Projecten maken

Werk ideeën uit tot software en verbeter je resultaat terwijl je eraan werkt.

Samenwerken

Werk met anderen aan opdrachten en bespreek hoe een project beter kan.

Leren door te doen

Van idee naar werkende software

Bij een project doorloop je steeds een aantal stappen. Je oefent deze stappen zelf, zodat je leert hoe je een idee omzet in een werkend en getest product.

  1. 1 Bedenk wat je wilt maken
  2. 2 Bouw het met code
  3. 3 Test het en verbeter het

Je hoeft nog niet te kunnen programmeren om met de opleiding te beginnen. Je leert de basis door te oefenen.
